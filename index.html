What it is

Embedded Linux devices - gateways, controllers, boards, smart devices of every kind - have to run for days without a crash, a reboot or a slow memory leak. Long Run Tool connects to the device's serial console, keeps the complete log of every session and watches the device while it runs: the memory and CPU of every process, crashes and other serious messages, reboots and memory leaks, drawn as live charts and summed up in a report at the end.

It only needs the console (a USB-serial cable) and the device's root password: nothing is installed on the device, and it works even when the device is unreachable over the network.

Long runs and soak tests

Leave several devices running for days: every line is saved, every crash, reboot and leak is caught, and each device's memory and CPU are charted.

Test cases

Run a plan of test cases, by hand or on a schedule; the report compares memory and CPU of each case.

Daily console work

A better serial terminal: filters, highlights, patterns, shortcut commands and buttons, and the log shared with your team in a browser.

  • One tab per device, and an All devices tab with every device's state, memory, CPU and charts.
  • Auto login as root (or the user you set) with the passwords you saved; the model and IP are found by themselves.
  • Memory and CPU of every process, polled from every second to every few minutes, with trends.
  • Live charts of free memory and total CPU (processes on request), events marked, minutes to days of history.
  • Big issues caught: segmentation faults, "not alive", out of memory, reboots - and your own rules.
  • Memory leak detection with robust trends over hours, not fooled by a single step.
  • Highlights, quick filter, search, blacklist and whitelist, with plain text or patterns.
  • Pattern suggestion: paste a few lines and the app writes the regular expression and explains it.
  • Share the log in any browser on your network or over TCP; with the access key, others can type commands too.
  • Change the IP through the console, pin a line, shortcut commands and shortcut buttons (web page, command, folder, program).
  • Test cases with notes, schedule and a report; a session report for every run.
  • Up to date: checks for new versions; Update now installs them and reopens your tabs.

Getting started

  1. Connect the device's serial console and start the app: the device's port is listed under Available COM ports. Click it - the log starts and is saved in a session folder.
  2. Add the device's root password once: click Add root password on the note over the charts (or Setup > Terminal Log Viewer > Root login). The app logs in and starts measuring.
  3. More devices: + opens a tab for each. Help > Tutorial (F1) shows every feature.

Download

Windows 10 / 11, 64-bit. One zip with everything in it: nothing else to install.

Download
From the latest release on GitHub
  • Unzip it (right-click > Extract All) anywhere you can write to, not Program Files, and start Long Run Tool.exe in the Long Run Tool folder.
  • Windows may say "Windows protected your PC" for a new app: click More info > Run anyway.
  • Your settings and saved passwords (encrypted for your Windows account) are kept in %APPDATA%\Long Run Tool, the logs of each session in device_logs next to the app.
  • Your USB-serial cable may need its driver (most install by themselves).

Updating

The app tells you when a new version is out: by itself once a day (a notice in the menu bar; switch it off in Help > Check for updates), or at once with Help > Check for updates. Click Update now: it downloads the new version, checks it, restarts and reopens your tabs, and keeps your settings and logs. If the app's folder cannot be written to, unzip the new version over it instead.

Network blocks this website? The app then checks on github.com instead, and the downloads are on the GitHub releases page.
